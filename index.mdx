Snitch is a tiny macOS menu bar utility built with Electron. It uses `lsof` and `ps` under the hood to discover every TCP process listening on your machine, then surfaces them in a clean popup — sorted so your project folders appear first. From there you can jump straight to `http://localhost:<port>` in your browser or terminate a stuck service without ever opening a terminal.

## What Snitch does

<Steps>
  <Step title="Lives in your menu bar">
    After launch, Snitch hides from the Dock and shows a `🐀 N` badge in the macOS menu bar — where `N` is the number of processes currently listening on local TCP ports. The count refreshes automatically every 4 seconds.
  </Step>
  <Step title="Click to see the popup">
    A single left-click on the tray icon opens a compact popup listing every listening process with its folder name, PID, and port(s). The list auto-refreshes every 2.5 seconds.
  </Step>
  <Step title="Open localhost in one click">
    Click any row to open `http://localhost:<port>` in your default browser. Rows with a detected port become clickable and show a pointer cursor.
  </Step>
  <Step title="Kill stuck services instantly">
    Hit the ✕ button on any row to send `SIGTERM` to the process. If it doesn't respond, Snitch automatically escalates to `SIGKILL`.
  </Step>
</Steps>

## Key features

<CardGroup cols={2}>
  <Card title="Project-folder first" icon="folder-open">
    Snitch prioritises processes whose working directory is a real project folder, filtering out most system noise.
  </Card>
  <Card title="Auto-refresh" icon="rotate">
    The process list refreshes every 2.5 s in the popup and every 4 s in the tray count — no manual polling needed.
  </Card>
  <Card title="Automatic updates" icon="cloud-arrow-down" href="/updates">
    Snitch checks GitHub Releases in the background and prompts you to restart when a new version is ready.
  </Card>

    Built with Electron, fully open source, and easy to run from source for development.
